Bisale is a small programming language interpreter written in Python. It is an experimental project that I am building to understand how a lexer and parser work.

## Project Structure

```text
Bisale/
│
├── Atil/
│   ├── Atil.py
│   ├── lexer.py
│   ├── parser.py
│   └── code_input.py
│
├── Image/
│   └── Bisale_icon.png
│
├── example.bisale
└── README.md
```

| File | Purpose |
|---|---|
| `Atil.py` | Main file |
| `lexer.py` | Converts source code into tokens |
| `parser.py` | Processes tokens, handles declarations and output |
| `code_input.py` | Reads `.bisale` files |
| `example.bisale` | Example Bisale program |

## Requirements

- Python 3.x
- Git

No external Python packages are required.

## Installation

Clone the repository:

```bash
git clone https://github.com/lyashwith/Bisale.git
cd Bisale
```

Run the interpreter:

```bash
python Atil/Atil.py
```

Enter the name of the `.bisale` file when prompted.

```text
Enter Bisale name to cook:
```

For example, enter `example` to read `example.bisale`.

Run the command from the repository root directory.

## Syntax

### Integer declaration

Use `int()` to declare integer variables.

```bisale
int(a)
```

### Integer declaration with values

```bisale
int(a=10)
```

### Multiple variables

```bisale
int(a,b,c)
```

### Multiple variables with values

```bisale
int(a=1,b=192,c)
```

### Output

Use `thojpav()` to print variable values.

```bisale
int(a=10)
thojpav(a);
```

Multiple variables can also be printed:

```bisale
int(a=10,b=20)
thojpav(a,b);
```

## Example

```bisale
int(i)
int(a=1,b=192,l)
int(cd=9)

thojpav(a);
thojpav(b,l);
```

## How It Works

```text
Source Code
    |
    v
   Lexer
    |
    v
  Tokens
    |
    v
  Parser
    |
    +------> Variable Dictionary
    |
    +------> Output
    |
    v
 Returned Dictionary
    |
    v
   Atil.py
    |
    v
  print()
```

### Lexer

The lexer reads the source code line by line and generates tokens.

It currently recognizes:

- `int`
- `thojpav`
- Identifiers
- Integer values
- `(` and `)`
- `=`
- `,`
- `;`

If unsupported syntax is encountered, it generates an `UNKNOWN` token.

### Parser

The parser receives the tokens generated by the lexer.

It handles:

- Integer variable declarations
- Variable initialization
- Multiple variable declarations
- Output statements

The parser stores variable values in a Python dictionary and handles output using `print()`.

## Token Types

| Token | Meaning |
|---|---|
| `INT` | `int` keyword |
| `OUTPUT` | `thojpav` keyword |
| `IDENTIFIER` | Variable name |
| `INTEGER` | Integer value |
| `LEFT_PARENT` | `(` |
| `RIGHT_PARENT` | `)` |
| `EQUAL` | `=` |
| `COMMA` | `,` |
| `SEMICOLON` | `;` |
| `UNKNOWN` | Unsupported syntax |

## Limitations

The current implementation has the following limitations:

- Only integer variables are supported.
- No variable reassignment.
- No arithmetic operators.
- No user input.
- No negative or decimal numbers.
- No strings.
- No conditional statements.
- No loops.
- No user-defined functions.
- No Abstract Syntax Tree (AST).
- No comprehensive syntax or semantic error handling.
- No proper validation of undeclared variables.
- The parser does not safely handle every malformed or incomplete statement.
